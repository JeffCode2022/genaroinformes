# Informe - Genaro Rojas Buleje

Aplicación web interactiva para generar informes en formato PDF. Permite editar contenidos directamente en la página web con vista previa en tiempo real, y exportar a PDF.

## Características

- 📄 Formato A4 personalizado
- ✏️ Campos editables en tiempo real
- 🖨️ Exportación a PDF
- 📱 Responsive design
- 🎨 Interfaz limpia con Tailwind CSS

## Uso

1. Abre `index.html` en tu navegador
2. Edita los campos directamente haciendo clic en ellos
3. Haz clic en el botón "Guardar como PDF" para descargar el informe

## Tecnologías

- HTML5
- CSS3
- Tailwind CSS
- JavaScript vanilla

## Instalación

No requiere instalación. Solo necesitas un navegador moderno.

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/Fundamentos_de_dart.git

# Abrir el archivo
open informes/index.html
```
